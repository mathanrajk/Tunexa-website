# Tunexa landing page
Static site (HTML + CSS + JS). No build step needed.

Deploy to Vercel: push this folder to GitHub and import it at vercel.com/new
(Framework preset: Other, no build command, leave output directory empty), or run `npx vercel` in this folder.

Before launch: replace YOUR-DOMAIN in index.html (og:image, og:url), the store links (href="#"),
the contact email, and the Privacy / Terms links. Edit text in index.html and styles in css/styles.css.
Note: css/styles.css is compiled Tailwind. New Tailwind classes won't exist until you rebuild it,
so add one-off styles as plain CSS at the end of the file.
